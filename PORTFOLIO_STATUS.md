The source string in `portfolio-repo/tools/verified-tests.json` records the exact command and the commit that was measured, and it is the only place a test count may be published from. Counts were measured between 2026-11-22 and 2026-11-27.
- **CI** is the latest completed workflow run on the default branch at generation time. A dash means GitHub returned no completed run in the API response used for this table.
- **Counts** use an explicit denominator: 64 public repositories = 60 open-source projects + this profile repository + the portfolio site + 2 archived forks. The open-source project count is the published metric; not every project is a security tool.

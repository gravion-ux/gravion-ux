# Security Policy

This repository contains Priyanshu Kumar Thakur's GitHub profile,
resume, portfolio status page, and profile images. It is not a
software product, but security reports about this repository are still
welcome.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately through GitHub private vulnerability reporting:
<https://github.com/gravion-ux/gravion-ux/security/advisories/new>

Email: priyanshukumarthakur937@gmail.com

Include the affected file or page, the impact you believe it has, and
the smallest reproduction you have. Never include credentials or
private personal data in a report.

## Scope

In scope:

- Incorrect or misleading security claims in the profile or status
  page that could put a reader at risk.
- Broken links that send readers to an unintended destination.
- Accidental exposure of private data in repository files or images.

Out of scope:

- Vulnerabilities in the separate tools linked from this profile.
  Report those in the relevant tool repository so the fix and credit
  stay with that project.

## Repository hygiene

GitHub secret scanning and push protection are enabled for this
repository. Dependabot checks GitHub Actions dependencies weekly.
